# 하이포스 방학 트레저 헌터

초등 영어·수학 방학 이벤트용 학습 퀘스트 웹앱입니다. 아이들은 반 코드 + 닉네임 + 숫자 4자리 비밀번호로 로그인해서 보물 지도를 따라가고, 선생님이 미션 완료와 보물 교환을 승인합니다.

## 주소
- 아이 화면: https://highfos-treasure-hunter.highfos.workers.dev/
- 선생님 화면: https://highfos-treasure-hunter.highfos.workers.dev/teacher

## 처음 시작하기
1. 선생님 화면을 열면 "선생님 계정 만들기"가 나와요. `SETUP_CODE.txt`에 있는 설정 코드, 아이디, 비밀번호(4자 이상)를 입력하세요. 선생님 로그인도 5번 틀리면 10분 동안 잠겨요. 이 과정은 한 번만 하면 되고, 계정을 만든 뒤에는 설정 코드가 더 이상 쓰이지 않아요.
2. **탐험대원** 화면에서 반을 만들면 반 코드가 나와요.
3. 아이 닉네임을 등록하면 처음 비밀번호 4자리가 **한 번만** 보여요. 로그인 카드에 적어서 아이에게 전해 주세요.
4. 아이가 처음 로그인하면 자기만의 비밀번호로 바꿔요.

## 보상 구조
미션 → **항해 포인트** → 보물섬 도착 → 아이가 **보물상자를 열면 보물 풀에서 랜덤으로 1개** → 선생님이 전달.
- 화폐는 항해 포인트 하나뿐이에요. 금화나 교환소는 없어요.
- 기본 보물섬은 3·6·9·12·16·20번 섬(300·600·900·1200·1600·2000 포인트)이라, 아이 한 명이 시즌 동안 받는 보물은 최대 6개예요. **시즌** 탭에서 바꿀 수 있어요.
- 어떤 보물이 얼마나 잘 나올지는 **미션·보물** 탭의 "뽑힐 비율"로 정해요. 재고가 0이 되면 그 보물은 더 이상 나오지 않아요.

## 하루 운영
- 아이가 미션에서 "완료했어요!"를 누르면 **요청 확인** 탭에 쌓여요. 확인하고 한 번에 승인하세요.
- 수업 중 한꺼번에 줄 때는 **미션 지급** 탭에서 미션과 아이들을 골라 바로 지급할 수 있어요.
- 아이가 보물상자를 열면 **보물 전달** 탭에 나타나요. 보물을 주고 "전달 완료"를 누르세요. 잘못 열린 상자는 "되돌리기"로 닫을 수 있어요.
- 비밀번호를 잊었거나 5번 틀려서 잠긴 아이는 대원 상세에서 "비밀번호 새로 발급"을 누르세요.
- 잘못 지급했으면 **기록** 탭에서 취소할 수 있어요.

## 보안·개인정보
- 실명 대신 닉네임만 쓰세요. 실명·전화번호·학교는 받지 않아요.
- 비밀번호는 해시로 저장되고, 5번 틀리면 10분 동안 잠겨요.
- 만 14세 미만 아이가 쓰므로, 이벤트 안내문에 학부모 동의 항목을 넣는 것을 권해요.

## Cloudflare 구성 (다른 작업물과 분리됨)
- Worker: `highfos-treasure-hunter`
- D1 데이터베이스: `highfos-treasure-hunter` (APAC)
- 시크릿: `SETUP_CODE`

## 개발
```bash
npm install
npx wrangler d1 execute highfos-treasure-hunter --local --persist-to "$TEMP/hipos-db" --file=schema.sql
npx wrangler dev --persist-to "$TEMP/hipos-db"
npx wrangler deploy
```
Windows에서 프로젝트 경로가 너무 길면 로컬 DB를 열지 못하니, `--persist-to`로 짧은 경로를 지정하세요.
